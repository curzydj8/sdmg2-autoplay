# 输入映射诊断报告

**日期**：2026-10-17
**问题**：A键槽位0无响应

## 根因

**不是键盘映射问题**，而是**测试时机错误**：

1. A/B/enter测试时，游戏已结束并回到ODDS屏
2. 在ODDS屏按任何打牌键都无效（预期行为）
3. 像素差异0.0是正确的——游戏确实没变化
4. 错误地将"游戏不在打牌阶段"解释为"按键映射失败"

## 证据

- 测试时间线：
  - 15:22 N+enter打發成功（游戏中）
  - 15:24 N+enter打三萬成功（游戏中）
  - 15:27 A键测试（游戏已结束，ODDS屏）
  - 15:29 B键测试（ODDS屏）
- 数据库：session 1未标记结束，实际游戏已回ODDS
- 截图post_e-view.png确认ODDS屏

## 6种场景排查结果

| 场景 | 结果 |
|------|------|
| 1. A键未发送到MAME | ❌排除（uinput无异常） |
| 2. 游戏未识别 | ❌排除（N+enter在游戏中有效） |
| 3. 选牌成功但enter未执行 | ❌排除（流程正确） |
| 4. 截图太早 | ❌排除（等待2秒足够） |
| 5. 画面无变化但误判 | ✅部分（0.0正确，但原因误判） |
| 6. 牌局已结束仍报告旧问题 | ✅**根因** |

## 修复

1. 动作确认前先检查游戏阶段
2. 非打牌阶段不执行打牌测试
3. session结束时标记result
4. 像素差异0.0时先查阶段，再下结论
