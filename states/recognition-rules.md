## 识别流程（state_detector.py）
```
1. 截屏 → PIL Image
2. 检查 S1：ODDS 模板匹配（阈值 0.85）
   → 匹配：返回 ("ODDS", conf)
3. 检查 S3：A-N 字母标记检测
   → 找到 ≥10 个字母标记：返回 ("GAMEPLAY", conf)
4. 都不匹配：返回 ("UNKNOWN", 0.0)，保存截图
```
